When a small GPT model—which had been pre-trained on the Aozora Bunko corpus of Atsushi Nakajima’s works—was further trained on Wikipedia entries for neuroscience terminology, the validation loss for the new domain decreased significantly, while the loss for the original domain increased. The model’s output also shifted from the original writing style to one centered on scientific terminology. This is a simplified reproduction of catastrophic forgetting in continuous learning.
